# Рилсы

Папка на ролик: `<дата>_<имя>`. Внутри лежат монтажный скрипт `render.py`,
скрипт обложки `cover.py`, тайминги фраз `timings.json`, обложка
`*-oblozhka.jpg` и лёгкая версия `*-tiktok.mp4` (до 15 МБ, её можно скачать
с телефона).

Полные версии `*-reels.mp4` в репозитории не хранятся: они по 30–40 МБ и
нужны только в момент постановки в Metricool. Для этого их временно
коммитят, забирают ссылку `raw.githubusercontent.com`, отдают Metricool
(он сразу копирует файл к себе на static.metricool.com) и убирают коммит
из ветки.

Исходники (запись HeyGen, картинки и клипы Kling) лежат отдельно:
записи HeyGen — в релизах репозитория, остальное — в файлах проекта.
Общие модули монтажа: `tools/reels`.
