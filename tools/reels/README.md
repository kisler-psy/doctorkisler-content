# Монтаж рилсов

Сборка вертикальных роликов из записи HeyGen, картинок и клипов Kling:
зум на говорящего, вставки между фразами, субтитры по фразам, крупные
заголовки и финальная карточка. Кадры собираются в PIL, склейка ffmpeg
(libx264, crf 17), звук берётся из записи HeyGen без изменений.

## Модули

| Файл | Зачем |
|---|---|
| `style.py` | надписи: узкий жирный капс Oswald, белый #F8F8F8 и красный #F4341C, мягкая тень, радиальное затемнение под текстом. Разметка: `*красное*`, `\|` — жёсткий перенос строки. Кегль сам уменьшается, если текст не влезает |
| `core.py` | таймлайн: планы (`Shot`), движение камеры, надписи (`Text`), рендер в ffmpeg |
| `cover.py` | обложка 1080×1920: затемнение, красный свет, рваные гранж-мазки под текстом |
| `dtw.py` | привязка фраз к речи: синтез espeak-ng тянется на запись по мел-спектру |
| `align.py` | длительности espeak-ng и паузы `ffmpeg silencedetect` |
| `dp.py` | раскладка фраз по паузам динамическим программированием (запасной путь) |
| `syll.py` | счёт слоговых вершин: проверка привязки без распознавания |
| `check.py` | лист кадров с надписями плюс детектор лиц |
| `phrases.py` | тексты фраз роликов 7 и 8 |

## Как привязываются субтитры

Распознавания речи в облаке нет: huggingface.co отдаёт модели через
`cas-server.xethub.hf.co` и `us.aws.cdn.hf.co`, а их прокси закрывает (403).
Поэтому фразы синтезируются espeak-ng (ru, скорость 160) и тянутся на
запись через DTW по мел-спектру (`dtw.py`), а границы потом подтягиваются
к серединам пауз из `silencedetect`. На роликах 7 и 8 все границы легли
в реальные паузы, два переноса внутри сплошной речи подтвердились счётом
слоговых вершин (`syll.py`).

## Что нужно на машине

```
apt-get install espeak-ng
pip install opencv-python-headless numpy pillow
```

Шрифт Oswald (переменный, ось Weight 200–700) кладётся в
`/opt/fonts/Oswald-VF.ttf`:

```
curl -sSL -o /opt/fonts/Oswald-VF.ttf \
  "https://raw.githubusercontent.com/google/fonts/main/ofl/oswald/Oswald%5Bwght%5D.ttf"
```

## Правила, зашитые в скрипты

- Заголовки на кадрах с говорящим не выше y=1000: там заканчивается голова.
- Субтитры в зоне 1350–1490, ниже 1500 не опускаются — там интерфейс Instagram.
- Текст никогда не заходит на лицо; на картинках ставится мимо лиц и главного предмета.
- Висячие предлоги в конце строки переносятся вниз (`style.HANGING`).
